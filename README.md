# hwei-shin.com

Personal site built with React, TypeScript, Tailwind CSS, and [Vite](https://vite.dev).

## Scripts

- `npm start` (or `npm run dev`): run the dev server at http://localhost:3000
- `npm run build`: typecheck and build to `build/`
- `npm run preview`: serve the production build locally
- `npm run deploy`: build and publish `build/` to the `gh-pages` branch
